# Haven installer releases

Installer downloads and release notes for Haven, the home-server platform.

This repository starts with private previews for testing on a disposable Raspberry Pi. Download installer assets from Releases. Use the versioned release notes for supported platforms, setup instructions and known limitations.

The first candidate is Haven `0.1.0~preview2` for ARM64. It offers ntfy, Uptime Kuma or both, a browser setup wizard, local naming and per-installation local certificates. Device certificate trust requires explicit approval. Fresh physical-Pi qualification is pending. The marketplace and Karma integration are still planned features.

Each release records its installer version, SHA-256 checksum and qualification status. Public distribution will include the required license notices, source availability and release verification instructions. A checksum alone is not a publisher signature.

Household configuration and user data do not belong in this distribution repository.
